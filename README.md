## 🎮 Como jogar

- Use as setas do teclado (`←` `→` `↑` `↓`) para mover o Pac-Man, ou deslize o dedo na tela em dispositivos móveis.
- Coma os pontinhos para ganhar pontos.
- Pegue as bolinhas grandes (Power Pellets) para deixar os fantasmas assustados e poder comê-los.
- Evite os fantasmas quando estiverem normais — você tem um número limitado de vidas.
- Coma todos os pontos do labirinto para vencer a fase.
